# Glossary — agent context

> Read by: all agents. Maintained by: Business Analyst.
>
> Purpose: the project's domain terms. Agents use the same word for the
> same thing — and disambiguate when the same word means two things.
>
> **Size class**: register — not byte-budgeted. A term is found by
> scanning the list, so the read this file exists for is the whole
> file, and a definition behind a pointer is one nobody looks up.
> There is no rule to keep and no Story record to spill, so there is no
> core/appendix split. The bound is the lifecycle: a term leaves when
> the project stops using it — never as a side effect of an edit that
> came for a different term.
